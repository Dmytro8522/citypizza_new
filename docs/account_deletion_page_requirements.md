# Требования к странице удаления аккаунта (App Store)

По ссылке для удаления аккаунта должен открываться ресурс, на котором:

1. Упомянуто название приложения или имя разработчика, указанные на странице приложения.
2. Размещена на видном месте пошаговая инструкция о том, как запросить удаление аккаунта.
3. Содержится информация о том, данные каких типов будут удалены или сохранены, и о сроках хранения.

## Для следующего шага

Когда вернёмся к задаче, используем этот файл как чеклист и подготовим готовую страницу `delete-account.html` под публикацию.
